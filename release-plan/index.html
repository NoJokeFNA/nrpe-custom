Release preparation plan

Status: SLES 12 SP3 support published, updated 2026-10-28. The actual deployment was confirmed as SLES 12.3, NRPE 2.15-4.24 and the OpenSSL 1.0 ABI. The previous SLE-15 targets were based on an incorrect platform assumption; their published test evidence remains historical and is not relabeled.

New work stays on a topic branch. Pushes, PR creation and merges into develop or master require an explicit maintainer request. Changes are handled sequentially. See Git workflow.

Remaining work, in priority order

  • [ ] Complete Windows Docker Desktop practical checks.
  • [ ] Complete Debian and SLES test VMs: real systemd/reboot, plugins and upgrade/rollback from the saved NRPE 2.15 package. Infrastructure is unavailable; the per-target worksheet is prepared, and execution remains blocked/not run.
  • [ ] Enroll a maintainer-controlled release key, configure the signing secret and authenticate a signed release after a separately requested master promotion.
  • [ ] Continue recurring maintenance review, including the legacy SLES 12 SP3 lifecycle and upstream NRPE updates.

The dated 2026-10-27 review records the old SP4 scope. SLES 12 SP3's published general/LTSS end dates are 2019-06-30 and 2022-06-30; archive access is not an extension of vendor support. See the SUSE lifecycle.

Published evidence and future releases

The current SLES 12 SP3 release passed all five target gates and publication. Historical SLE-15 results retain their actual platform labels in the release history.

Each future release must pass the publication gate for its exact clean commit. Previous passes, local tests and runtime-only reports cannot replace fresh release evidence. Publication and master promotion still require the maintainer's explicit request.
